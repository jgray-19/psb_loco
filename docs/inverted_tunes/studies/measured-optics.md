# Measured optics

PSB ring 3 · AC-dipole turn-by-turn and the tune/chroma scan · 4 machine configurations, each against two reference lattices. Every beta bar is omc3's propagated error added in quadrature to a bootstrap over the folder's AC-dipole kicks.
